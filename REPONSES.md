# Réponses au TP 1 — Git et GitHub

## Question 1
`git add` prépare les fichiers pour le prochain commit. `git commit` enregistre les changements dans l’historique Git.

## Question 2
Un commit est un instantané du projet à un moment donné, conservé dans l’historique avec un message.

## Question 3
Une branche permet de développer une fonctionnalité séparément de la branche principale, puis de la faire examiner avant de la fusionner.

## Question 4
Une Pull Request propose des changements pour examen et discussion avant leur fusion dans une autre branche.
